Request access: thecozycod3r/social-media-dash

The problem

A workflow built on chaos.

The social media team at DAM operated with zero structure. Creating content meant: Social media manager creates a mood board → sends to WhatsApp → manager approves (or forgets) → sends to copywriter → sends to designer → back to manager → finally to the client → someone manually posts it.

Everything lived in Slack threads and WhatsApp messages that scrolled off. Things got lost. Deadlines were missed. Nobody knew where any piece of content was in the pipeline.

Approval chains across Slack + WhatsApp

Content lost in message threads

No visibility into pipeline status

Missed deadlines, duplicated work

Manual posting by the social media manager

Error-prone, time-wasting

The solution

A single platform for every step.

I built a custom social media planning and approval platform using AI-assisted development (Claude), Supabase as the backend, and Vercel for deployment. The goal: a single source of truth for every piece of content in flight, from ideation to post.

Features

Everything the team needed, nothing it didn't.

Content Calendar

Visual calendar view showing all scheduled, in-review, and published content. Team can see the full month at a glance and spot gaps before they become problems.

In-App Mood Board

Creatives can build mood boards directly in the tool instead of sending image dumps over WhatsApp. Everything stays attached to the content brief.

Multi-Stage Approval Flow

Structured flow: Manager → Copywriter → Designer → Manager → Client. Each stage has a clear owner. Content can't skip stages or get lost in a thread.

Automated Publishing

Once approved, content posts automatically to Instagram and Facebook via the Meta API on the scheduled date. No manual posting, no missed slots.

Tech stack

Lightweight, scalable, AI-assisted.

The entire product was built using AI-assisted development (vibe coding with Claude). Supabase handled auth, the database, and real-time updates. Vercel provided instant deployments. The Meta API enabled automated publishing to both Instagram and Facebook without manual intervention.
