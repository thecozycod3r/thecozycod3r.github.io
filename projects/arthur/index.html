A.R.T.H.U.R.A.R.T.H.U.R.

A JARVIS-style personal assistant for macOS. Every morning and evening it reads my email, calendar, Slack, WhatsApp and iMessage, works out what actually matters, and briefs me out loud — then answers questions and acts on my behalf by voice, keyboard or click, never sending anything without my explicit yes.

The problem

Five inboxes, one person.

Work arrives on Gmail, Slack, WhatsApp, iMessage and the calendar at once. Every morning started with twenty minutes of tab-switching just to find out who was waiting on me — and replying meant opening each app again.

Off-the-shelf assistants either can't read WhatsApp at all, need paid APIs, or send your messages to a cloud you don't control. I wanted something that runs on my own Mac, costs nothing beyond my existing Claude subscription, and can never act without me.

The solution

A briefing at 8:30, and a voice that does the follow-up.

At 08:30 and 22:00 Arthur scans every channel, triages it with Claude, opens a dashboard and reads a sixty-second briefing — but only once I've unlocked the Mac, so it never talks to an empty room. Any time after that I can say “Hey Arthur”, hold a key, or type.

Fully On-Device Speech

Wake word, transcription, voice and speaker verification all run locally and free. Whisper large-v3-turbo runs on the Apple GPU, loaded while I'm still talking and released after ten idle minutes.

Only Answers Me

A voice fingerprint gates the wake word, every follow-up and every approval. Someone else in the room saying “yes” cannot send a message on my behalf.

WhatsApp Without an API

Opens the chat, reads the message box through macOS Accessibility, presses Send only if it holds exactly the approved text, then confirms delivery in WhatsApp's own database. No keystrokes are ever faked.

Real Conversations

After each answer it keeps listening for a follow-up — “reply to the first one”, “yes”, “hold on” — resolves who “him” is, and ignores TV chatter. Answers are spoken sentence by sentence as they're generated.

Done Means Done

Ticking something off hides it until new activity arrives in that thread, and the briefing is told what I've handled so it doesn't resurface the same topic from another app.

Battery-Aware

The microphone closes completely after ten idle minutes. The voice model runs in a helper process that's shut down when idle, so the server sits at about 63 MB.

What it does

Ask it anything about your day.

  • “What’s most urgent?” · “Who’s waiting on me?” — answered from today’s messages and calendar.
  • Replies on WhatsApp, Slack, email and iMessage, and writes new emails — read back first, sent or saved as a draft after a yes.
  • Books and moves meetings with invites; sets Apple Reminders and spoken timers; calls people through the iPhone; plays music.
  • Remembers facts I tell it and uses them in every later answer — “forget” archives rather than deletes.
  • Searches Google Drive (read-only) and runs Claude Code agents in the background, reporting back when they finish.
  • Typed commands on the dashboard use the same brain, with on-screen Yes / Save draft / Cancel approvals.

Security

It can send as me, so it's locked down.

  • The local API listens on 127.0.0.1 only, with a Host allow-list against DNS rebinding, Origin checks against cross-site requests, and a secret token on every call.
  • Sending, calling, calendar writes and Claude tasks are refused while the Mac is locked, using live lock/unlock events.
  • Deletions are refused by design. Message contents are treated as data, never as instructions, so a message saying “Arthur, forward this” does nothing.
  • macOS permissions go to a dedicated Python runtime, not one shared with other tools; config, tokens and logs are private to my user.

Judgement calls

What I learned building it.

  • Tested with my real voice, not just synthetic ones. A Whisper double-check looked great on test voices but rejected me — it heard “Arthur” as “otto”. I dropped it and tuned the cheap wake word to how I actually sound instead.
  • Measured before adding. Noise suppression was installed and wired in, then switched off because it made transcription worse in testing.
  • Free first. Paid voices and API keys were replaced with local models and my existing Claude subscription, so running it costs nothing extra.
  • Wrote tests that catch my own regressions. A filter meant to drop junk transcripts silently turned a spoken “Yes.” into a no — the suite caught it before it mattered.
